# フリマ在庫リスト

メルカリの在庫・ステータス・売上をブラウザで管理するシンプルなアプリです。
HTML 1ファイルだけで動き、ビルドやサーバーは不要です。

## 機能

- 商品の追加・名前の編集・削除（右上の「編集」）
- ステータス管理：未獲得 / 販売中 / 梱包済み / 発送中 / 完了
  - ラベルをタップしてドロップダウンで変更
  - 左の丸をタップで「完了」に切り替え
- ステータス別の件数タイルと絞り込み
- 商品ごとの獲得金額・売上金額と利益
- 収支サマリー（獲得合計・売上合計・利益）。絞り込み中はその商品だけで集計

## 使い方

`index.html` をブラウザで開くだけで使えます。

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で
ブランチ（例: `main`）とフォルダ（`/ (root)`）を選ぶと公開されます。

## データの保存

データはブラウザの `localStorage`（キー: `zaiko-v1`）に保存されます。

- 同じブラウザ・同じ端末でのみ保持されます（スマホとPCでは共有されません）
- ブラウザのサイトデータを消すと消えます
- 初回はサンプル商品が5件入っています
